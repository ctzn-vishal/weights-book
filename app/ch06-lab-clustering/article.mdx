## The same regression, six standard errors

A panel of 50 states over 20 years, 10 people interviewed in each state and year, and a policy that <Fact id="ch6lab.open_treated" /> of the states adopt somewhere in the middle of the window. The data are simulated, and the policy does nothing: its true effect is exactly zero. A regression of the outcome on the policy indicator with state and year fixed effects gives a coefficient of <Fact id="ch6lab.open_coef" /> on <Fact id="ch6lab.open_n" /> observations. Under fixest's default variance the standard error is <Fact id="ch6lab.open_se_iid" /> and the p-value is <Fact id="ch6lab.open_p_iid" />. Change one argument so that the standard error is clustered by state and it becomes <Fact id="ch6lab.open_se_state" />, <Fact id="ch6lab.open_ratio_state" /> as large, with a p-value of <Fact id="ch6lab.open_p_state" />. Four other arguments give four other numbers in between. Across the six, the largest standard error is <Fact id="ch6lab.open_span" /> the smallest (Figure L6.1).

Nothing in the output says which is right. [Chapter 6](/ch06-clustering) gave the principle: a standard error describes a repetition, and clustering is a question about which observations move together when the study is repeated, through sampling or through assignment <Cite id="abadie2023" />. This lab is the working companion to that principle. It takes six designs that economists use constantly, each with a source of variation that is clear by construction, runs every relevant option on fixest's variance menu, and counts how often a nominal 5 percent test rejects a true null <Cite id="berge2026" />. A test that rejects a true null far more often than 5 percent is describing a repetition that never happens.

## The menu

Every estimator in this lab is a `vcov` argument to `feols()` in fixest, with its pyfixest counterpart alongside. The formulas are the same in both; only the names differ.

| What it allows | fixest | pyfixest |
|---|---|---|
| Independent, identically distributed errors | `vcov = "iid"` | `vcov = "iid"` |
| Any heteroskedasticity, no correlation (HC1) | `vcov = "hetero"` | `vcov = "hetero"` |
| Any correlation within a group, none between (CRV1) | `vcov = ~state` | `vcov = {"CRV1": "state"}` |
| Correlation within either of two non-nested groups | `vcov = ~region + industry` | `vcov = {"CRV1": "region+industry"}` |
| Correlation within the intersection of two groups | `vcov = ~state^year` | `vcov = {"CRV1": "state_year"}` on a constructed column |
| Serial correlation within a unit up to a lag (Newey–West) | `vcov = NW(4) ~ id + time` | `vcov = "NW"`, `vcov_kwargs = {"lag": 4, ...}` |
| Cross-sectional and serial correlation in a panel (Driscoll–Kraay) | `vcov = DK(4) ~ time` | `vcov = "DK"`, `vcov_kwargs = {"lag": 4, ...}` |
| Spatial correlation within a distance cutoff (Conley) | `vcov = conley(300) ~ lat + lon` | not yet available |
| Leave-one-cluster-out jackknife (CRV3) | not built in; the `summclust` package computes it for fixest models | `vcov = {"CRV3": "state"}` |

Two facts about the menu matter more than any row. The first is that the default moved. Through version `0.12`, fixest clustered by the first fixed effect whenever a model had fixed effects; since `0.13.0` the default is IID for every estimation, and the old behavior has to be requested with `setFixest_vcov(all = "cluster", no_FE = "iid")`. The same script therefore reports different standard errors depending on which version is installed, and neither default was chosen with any particular design in mind. pyfixest `0.60`, as installed here, also reports IID unless told otherwise. A regression table whose note says "standard errors clustered by state" should get that from an argument the analyst wrote, never from a default.

The second is the small-sample correction. fixest's defaults, `ssc(K.adj = TRUE, K.fixef = "nonnested", G.adj = TRUE, G.df = "min", t.df = "min")`, scale a clustered variance by $$G/(G-1)$$ and compare the $$t$$ statistic with a $$t$$ distribution on $$G - 1$$ degrees of freedom, where $$G$$ is the number of clusters, or the smaller of the two counts under two-way clustering. These match Stata's conventions, and the lab uses them throughout, so every rejection rate below already includes the standard finite-cluster adjustment <Cite id="cameron2015" />.

```r
library(fixest)
f <- feols(y ~ d | state + year, data = panel)
etable(f, vcov = list("iid", "hetero", ~state^year, ~state + year, ~state, DK(4) ~ year))
```

```python
import pyfixest as pf
panel["state_year"] = panel["state"].astype(str) + "_" + panel["year"].astype(str)
for v in ["iid", "hetero", {"CRV1": "state_year"}, {"CRV1": "state+year"}, {"CRV1": "state"}]:
    print(v, pf.feols("y ~ d | state + year", data=panel, vcov=v).se()["d"])
```

## Six designs with a known answer

Each design below draws <Fact id="ch6lab.reps" /> data sets from a process in which the coefficient of interest is exactly zero, estimates the same regression on each, and records how often each `vcov` argument produces a p-value below 0.05. The Monte Carlo standard error of a rejection rate whose true value is 5 percent is about <Fact id="ch6lab.mc_se_at_5" /> points, so a rate near 5 percent is a pass and a rate of 10 percent is not noise. The designs are stylized on purpose. Gaussian shocks, equal cluster sizes, and a single persistence parameter fix the mechanism in each case without pretending to reproduce any particular data set. Figure L6.2 collects the results; the text takes them one design at a time.

### An experiment randomized at two levels

Tennessee's Project STAR assigned students and their teachers to small or regular classes within schools, so the class, not the student, was the unit of assignment <Cite id="krueger1999" />. Compare that with a program assigned by an individual lottery inside each school. The simulated experiment has 40 schools with 4 classrooms each and <Fact id="ch6lab.exp_n" /> students, school and classroom shocks, and a treatment effect that varies by classroom around an average of exactly zero. The regression has school fixed effects. Two arms differ only in the assignment: student by student, or half the classrooms in every school.

Under student-level assignment the heteroskedasticity-robust standard error rejects the true null <Fact id="ch6lab.rej_exp_individual_hetero" /> of the time. Clustering by classroom rejects <Fact id="ch6lab.rej_exp_individual_class" /> of the time and clustering by school <Fact id="ch6lab.rej_exp_individual_school" />. The clustered intervals are not wrong so much as far too wide: they describe a repetition in which whole classrooms are redrawn, and in this arm they are not. Because every classroom is in the sample and treatment varies within each one, the design gives no reason to cluster, and clustering anyway is conservative in the sense <Cite id="abadie2023" narrative /> describe. Under classroom-level assignment the ranking reverses. The robust standard error rejects <Fact id="ch6lab.rej_exp_classroom_hetero" /> of the time, clustering by classroom <Fact id="ch6lab.rej_exp_classroom_class" />, near the nominal level, and clustering by school <Fact id="ch6lab.rej_exp_classroom_school" />. The correlation of outcomes within classrooms is identical in the two arms. What changed is the level at which treatment was assigned, and that is what the standard error must follow.

### A regressor that varies only by state

<Cite id="moulton1990" narrative /> studied regressions of individual outcomes on variables measured for the individual's state, such as a state unemployment rate, and showed that the textbook standard error can be too small by a large factor even when the within-state correlation of the errors is modest. The simulated version has 50 states with 200 people each, <Fact id="ch6lab.moulton_n" /> observations, a regressor of interest that takes one value per state, an individual covariate, and a state shock that gives an intraclass correlation of <Fact id="ch6lab.moulton_icc" />. For a regressor constant within equal-sized clusters, the IID standard error should be inflated by $$\sqrt{1 + (m-1)\rho}$$, with $$m$$ the cluster size and $$\rho$$ the intraclass correlation, which is <Fact id="ch6lab.moulton_pred" /> here (Appendix B derives it). The realized ratio of the state-clustered to the IID standard error averages <Fact id="ch6lab.ratio_moulton_state" /> across replications.

The IID standard error rejects the true null <Fact id="ch6lab.rej_moulton_iid" /> of the time and HC1 <Fact id="ch6lab.rej_moulton_hetero" />: heteroskedasticity was never the problem, so the heteroskedasticity-robust estimator does nothing. Clustering by state rejects <Fact id="ch6lab.rej_moulton_state" /> of the time. Two hundred people per state contribute to how precisely each state's outcome is measured; they do not multiply the number of states. The Moulton factor is a special case of the clustering component of a design effect, for a regressor that does not vary within clusters, and the general cluster-robust estimator covers it and the cases it does not <Cite id="cameron2015" />.

### Difference-in-differences with persistent state shocks

<Cite id="bertrand2004" narrative /> assigned placebo laws to random states in Current Population Survey wage data and found that standard difference-in-differences inference rejected the null of no effect far more often than its nominal level, because state shocks persist from year to year and the policy indicator is itself persistent. The simulated design is the opening panel: 50 states, 20 years, 10 people per state-year, <Fact id="ch6lab.did_n" /> observations, state shocks that follow a first-order autoregression with coefficient $$\rho = 0.8$$, and a placebo policy adopted by half the states in a year drawn between the sixth and the fifteenth. State and year fixed effects are included, and they change nothing about the dependence: they remove each state's level and each year's level, not the shock a state carries from one year into the next.

HC1 rejects <Fact id="ch6lab.rej_did_g50_hetero" /> of the time. Clustering by state-year, which allows the 10 people in a cell to be correlated and treats the cells as independent, rejects <Fact id="ch6lab.rej_did_g50_stateyear" />, which answers the prediction. Clustering by state rejects <Fact id="ch6lab.rej_did_g50_state" /> and two-way clustering by state and year <Fact id="ch6lab.rej_did_g50_twoway" />. The state is where the policy was assigned and where the shocks persist; the state-year cell is a level with no mechanism behind it, and clustering there is the defensible-looking wrong answer of this design.

With 10 states instead of 50, and <Fact id="ch6lab.did10_n" /> observations, clustering by state rejects <Fact id="ch6lab.rej_did_g10_state" /> of the time and two-way clustering <Fact id="ch6lab.rej_did_g10_twoway" />, while HC1 and state-year clustering still reject <Fact id="ch6lab.rej_did_g10_hetero" /> and <Fact id="ch6lab.rej_did_g10_stateyear" />. Here the $$t(G-1)$$ reference distribution is doing real work, and the design is friendly: equal-sized states and half of them treated. When the treated clusters are few or unusually sized, CRV1 with $$t(G-1)$$ can fail badly, and the wild cluster bootstrap or the CRV3 jackknife of Chapter 6 is the remedy <Cite id="mackinnon2017,mackinnon2023" />. At the limit of two clusters, one treated state and one comparison state as in the New Jersey and Pennsylvania minimum-wage study, clustering by state is not possible at all, and inference has to come from a model of the group-level shocks or from the group-level regression of <Cite id="donald2007" narrative /> <Cite id="card1994" />.

### Two non-nested dimensions

Bilateral trade flows share shocks with every other flow from the same exporter and with every other flow to the same importer. A firm-year panel in finance has firm shocks that persist and year shocks that hit every firm <Cite id="petersen2009" />. A regression of regional outcomes by industry has regional shocks and industry shocks. These groups are not nested, so no single clustering covers both, and <Cite id="cameron2011" narrative /> showed how to combine them: the variance clustered by the first dimension, plus the variance clustered by the second, minus the variance clustered by their intersection. The simulated design has 50 regions and 30 industries, <Fact id="ch6lab.twoway_cells" /> cells, with a region component and an industry component in both the regressor and the error.

HC1 rejects <Fact id="ch6lab.rej_twoway_hetero" /> of the time. Clustering by region alone rejects <Fact id="ch6lab.rej_twoway_region" /> and by industry alone <Fact id="ch6lab.rej_twoway_industry" />; each captures one dimension of the dependence and misses the other. Two-way clustering rejects <Fact id="ch6lab.rej_twoway_twoway" />. Two details are easy to get wrong in code. The two-way formula `~region + industry` is not the intersection `~region^industry`; with one observation per cell the intersection is just HC1. And the two-way variance matrix is a difference of matrices and need not be positive definite; fixest repairs it by replacing negative eigenvalues, and reports when it has done so.

### Spatial correlation

Rainfall and temperature shocks, distance to a new road or a mine, and exposure to a neighboring county's policy all vary smoothly over space, and so do the unobserved determinants of the outcomes they are used to explain. <Cite id="conley1999" narrative /> proposed a variance estimator that lets any two observations be correlated with a weight that declines with the distance between them and reaches zero at a cutoff. The simulated design places <Fact id="ch6lab.spatial_points" /> points on a lattice half a degree apart, roughly 40 to 55 kilometers, and draws both the regressor and the error as spatial fields whose correlation decays exponentially with a range of 150 kilometers, plus white noise. It also imposes 25 arbitrary administrative blocks of 8 by 8 points, the kind of unit an analyst might cluster by for want of anything better.

HC1 rejects <Fact id="ch6lab.rej_spatial_hetero" /> of the time. Clustering by the 25 blocks rejects <Fact id="ch6lab.rej_spatial_block" />: the blocks capture correlation among points that happen to fall in the same block and none across a block boundary, and a point near a boundary is as correlated with its neighbor across the line as with its neighbor inside it. A Conley cutoff of 100 kilometers, shorter than the range of the dependence, rejects <Fact id="ch6lab.rej_spatial_conley100" />. A cutoff of 300 kilometers, twice the range, rejects <Fact id="ch6lab.rej_spatial_conley300" />, the best of the menu and still a few points above nominal, as kernel variance estimators tend to be. A cutoff of 600 kilometers rejects <Fact id="ch6lab.rej_spatial_conley600" />, worse than 300, because a wider window averages over far more pairs and the variance estimate itself becomes noisy, and fixest has to repair its positive definiteness more often. The cutoff is a bandwidth, with the usual trade-off: too short misses dependence, too long buys nothing and costs precision. <Cite id="barrios2012" narrative /> make the related point for state-level policies: when the outcomes of neighboring states are correlated, clustering by state does not remove all of the dependence, and the assignment of the policy is what determines whether the residual correlation matters.

### Persistent common shocks in a panel

Macro panels, cross-country regressions, and asset-pricing panels share shocks that hit every unit in a period and persist across periods, with units differing in how exposed they are. <Cite id="driscoll1998" narrative /> extended the Newey–West estimator to this setting: sum the scores across units within each period, then apply a kernel over time to the period sums <Cite id="newey1987" />. The simulated panel has 50 units over 400 periods, a monthly panel of a few decades, with <Fact id="ch6lab.common_n" /> observations, unit and period fixed effects, and two independent first-order autoregressive common factors with $$\rho = 0.7$$, one entering the regressor and one the error, with the same unit-specific loadings on both. Units heavily exposed to the one shock are heavily exposed to the other, which is the realistic case. The period fixed effects remove the average exposure; the heterogeneous part remains.

Clustering by unit rejects <Fact id="ch6lab.rej_common_unit" /> of the time and Newey–West within unit <Fact id="ch6lab.rej_common_nw" />: both allow any persistence within a unit and no correlation between units in the same period, which is where the dependence lives. Two-way clustering by unit and period rejects <Fact id="ch6lab.rej_common_twoway" />; the period clusters capture the contemporaneous cross-sectional correlation and treat consecutive periods as independent, which the persistent factors violate. Driscoll–Kraay with eight lags rejects <Fact id="ch6lab.rej_common_dk" />, the closest of the menu and still above the nominal level. The remaining excess is the familiar finite-sample downward bias of kernel estimators under strong persistence, and doubling the lag does not remove it. The estimator needs a long time dimension, since the period sums are the effective observations. In a shorter panel the design gave the same ranking with every rate higher, and with a few dozen periods the choice returns to two-way clustering with an honest count of periods.

## What guides the choice

The six designs agree on one procedure, and it starts from the regressor, not from the residuals.

1. **Find the level at which the variable of interest is assigned or varies as a block.** A policy adopted by states, a class size set for classrooms, a shock measured for industries. That is the coarsest level at which a repetition redraws the regressor, and it is the first candidate for the cluster. Correlated residuals below that level do not by themselves call for clustering; correlated residuals above it are not removed by fixed effects.
2. **In a nested hierarchy, take the coarser level when the assignment happens there.** Students within classrooms within schools: cluster by classroom when classrooms are assigned, by school when schools are, and not at all when students are, whatever the intraclass correlation. This is the sense in which the "cluster at the coarser level" rule holds, inside the full sampling-and-assignment statement <Cite id="abadie2023" />.
3. **When two dimensions of dependence are not nested, use both.** Region and industry, firm and year, exporter and importer. Two-way clustering is not clustering by the intersection.
4. **When dependence follows a distance rather than a group, use a kernel.** Conley for space, Newey–West for time within a unit, Driscoll–Kraay for time across all units. The cutoff should cover the range of the dependence, and a much wider cutoff degrades the estimate rather than protecting it.
5. **Count the clusters before trusting the answer.** With fewer than about 50, report CRV3 or the wild cluster bootstrap beside CRV1; with fewer than about 10, randomization inference or a group-level model <Cite id="cameron2015,mackinnon2023" />. The counts are prompts to compare estimators, not thresholds.
6. **Some designs are off this menu.** In a shift-share regression the regressor is a weighted sum of industry shocks, and units with similar industry mixes share the same shocks even when they are far apart, so neither regional clustering nor a spatial kernel describes the repetition; the inference has to be organized around the shocks themselves <Cite id="adao2019" />. Spillovers between units and matched-pair designs raise similar issues.
7. **Write the argument down.** In fixest, `vcov = ~state`; in pyfixest, `vcov={"CRV1": "state"}`; in Stata, `vce(cluster state)`. A default is a software decision that has already changed once, not a design decision.

The worksheet at the end of [Chapter 6](/ch06-clustering#filling-in-the-worksheet) asks for the same inputs, the sampling mechanism, the assignment mechanism, and the number of clusters, and returns the same recommendations. This lab is the evidence that the recommendations hold when the truth is known.

<NotEstablished>

- **That these rejection rates transfer to any particular data set.** The designs fix a mechanism and a magnitude. Real intraclass correlations, persistence, and spatial ranges differ, and so do the rejection rates that follow from ignoring them.
- **That the matching estimator is exact in small samples.** Each design has enough clusters, periods, or spatial extent for the estimator that fits it to work with fixest's default corrections. With 10 states the design was deliberately friendly; unequal or few treated clusters need the remedies of Chapter 6.
- **That the right cutoff is knowable from the data alone.** The Conley and Driscoll–Kraay results depend on a cutoff and a lag chosen with the dependence range in view. In practice the range is an assumption, and reporting several cutoffs is part of the analysis.
- **That the finite-population and superpopulation questions coincide.** In the individually randomized experiment, clustering by classroom is conservative because every classroom is observed and the target is the average effect over those classrooms. For an average over a population of classrooms from which these were drawn, the clustered interval is the relevant one. The choice is a choice of estimand, and the simulation took one side of it.
- **That the coefficients mean anything causal.** Every design here is a placebo with a true effect of zero. Standard errors describe the repetition; identification is a separate question that no `vcov` argument answers.
